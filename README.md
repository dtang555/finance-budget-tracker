# finance-budget-tracker 

\# Finance \& Budget Tracking App



A web app for tracking income and expenses, setting budgets, and viewing spending summaries. Built for CPS714 using Scrum.



\## Features



\*\*Sprint 1 (in progress)\*\*

\- User registration, login, and logout

\- Add income and expense transactions

\- Edit and delete transactions

\- Transaction categories (Food, Transport, Bills, Salary)



\*\*Planned\*\*

\- Monthly budgets and category spending limits (Sprint 2)

\- Dashboard, income vs. expense summary, spending charts, budget alerts (Sprint 3)

\- Export financial summary and UI polish (Sprint 4)
